>
> Часть антивирусов относит WinDivert к инструментам повышенного риска или хакерским средствам. В результате файл удаляется и отправляется в карантин. Название такого детектирования обязательно содержит `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса или выключите обнаружение PUA (потенциально нежелательных приложений). Например, Kaspersky предлагает настройку "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При точной настройке исключений предпочтительно добавить исключение, но если вы не уверены в своих действиях, рекомендуется отключить детектирование PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и укажите поставщика, отличного от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем "Выбрать провайдера/поставщика" и вручную введите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы - [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 рекомендуется использовать этот вариант
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/releases/latest)

3. Откройте свойства архива и отметьте "Разблокировать". При распаковке через 7-Zip или PeaZip этот пункт можно не выполнять

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите необходимый файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для запуска стратегии вместе с системой используйте **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно вам**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавление выбранной стратегии в автозапуск (services.msc)</ins>
  - **`Remove Services`** - удаление стратегии и WinDivert из служб
  - **`Check Status`** - просмотр состояния обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** - включение или отключение обхода для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения настройки стратегию нужно перезапустить.**  
  Текущее состояние указано в скобках (включено/выключено).
  - **`IPSet Filter`** - выбор режима обработки сервисов из `ipset-all.txt`.  
  Это может пригодиться при проверке ресурса, который без zapret открывается нормально  
  В скобках показывается текущее состояние:
    - `none` - проверка не применяется ни к одному IP
    - `loaded` - IP сопоставляются со списком
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** - включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** - замена выбранного фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** - загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** - ручная проверка обновлений
  - **`Run Diagnostics`** - поиск распространённых причин, из-за которых zapret может не запускаться или не работать.  
  В конце диагностики можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапного сбоя
  - **`Run Tests`** - проверка стратегий специальной утилитой:
    - `Standard tests` - тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При отдельном запуске стратегии, не через service, должен появиться процесс winws.exe, который виден на панели задач.  
Если его нет, обратитесь к [#522](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните по очереди следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и запустите **`Update hosts file`**. Если текущий hosts окажется устаревшим, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота
  - Откройте текстовым редактором от имени администратора файл `hosts` в появившемся каталоге
  - Вставьте скопированные строки в конец `hosts` или замените ими ранее добавленные аналогичные записи
  - Сохраните файл и проверьте подключение снова. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работа не гарантируется. При отсутствии результата используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/NebulaMonitorKiln/tg-ws-proxy) или любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Одна и та же стратегия способна работать некоторое время, а затем перестать работать после её обнаружения.
> В репозитории есть разные варианты обхода. Если готовые стратегии не помогают, создайте новую на основе одной из них и измените её параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` -> `Run Diagnostics` не показывает ошибок

- Проверьте, внесён ли адрес нужного ресурса в списки доменов или IP

- Переключитесь на другие стратегии, например **`ALT`** или **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- См. [#765](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце выберите Y
- Удалите каталог zapret
- Скачайте свежую версию [со страницы релизов](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть "Разблокировать", отметьте её, нажмите "Применить" и затем "ОК"
- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов
- Запускайте разные скрипты `general` и проверяйте доступ к ресурсам. Если интернет-ресурсы не открываются, завершите программу через значок замка на панели задач и попробуйте другую стратегию
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service`

### Не работает игра/приложение с включённым запретом

- Проверьте в service.bat, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может повлиять на неожиданные ресурсы.

### Античит ругается на WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` файлами с теми же именами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Найдите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Попробуйте остальные стратегии, особенно если прежний вариант перестал работать.
- Дополнительная информация есть в [#251](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) включён
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её
- В `service.bat` откройте `Run Diagnostics` и очистите там кэш Discord
- Проверьте приложение Discord и выясните, помогла ли очистка кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ей
- Если браузерная версия тоже не открывается, последовательно проверьте остальные стратегии. YouTube и Discord могут работать на разных стратегиях
- См. также [#252](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/NebulaMonitorKiln/tg-ws-proxy)
- Либо используйте бесплатные MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить работу каждой из них невозможно.

Обычно помогает такой порядок действий:
- через `service.bat` обновите ipset и активируйте `Game Filter`
- если результата нет, дополнительно включите `ipset any`

Учтите, что `ipset any` способен нарушить открытие многих сайтов. Не оставляйте этот режим включённым постоянно. Вместо этого определите все IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`

Если это не решило проблему, создайте тему в разделе [Discussions](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [здесь](https://github.com/NebulaMonitorKiln/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Новые адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены-исключения, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
